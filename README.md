# qyn-central

QYN 信息中心的**中控侧**：部署脚本、systemd 用户单元、状态墙与大屏 GUI。

## 目录

| 路径 | 作用 |
|---|---|
| `deploy/` | 发布与安装脚本（构建发布包 → 传输 → 远端解包装配 → 失败回滚） |
| `scripts/` | 各种落地脚本：到点唤醒驱动器、状态墙发布、探针、账号轮切与额度降级 |
| `dsh/` | DSH（DeepSeek Harness）相关：profile 补丁与说明 |
| `GUI/` | 大屏：页面（`screen/`）、状态墙服务端（`status-wall/`）、只读桥（`time-panel/`） |
| `tools/` | 小工具 |

设计上分成三层：**控制层**（定时/唤醒/管道）→ **数据工具层**（内核，另有仓库）
→ **智能体层**（只做语义判断）。控制层不碰业务语义，只负责"什么时候叫醒、谁来发、发到哪"。

## 几个关键约定

- **一次只跑一轮**：所有入口（定时、手机消息、大屏按钮、对话）共用一把跨进程锁，
  拿不到就立刻报忙，**不排队、不自动重试**。
- **输入输出由管道决定**：Agent 只产出回复文本，回哪条通道由管道按触发来源确定性决定。
- **同样的内容不重发**：出站失败会把正文存进待补发队列，下一轮先补发，成功即删。
- **大屏只读**：页面所有数据来自只读接口，写操作只走内核的写入口。
